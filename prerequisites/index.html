This course never re-teaches these four ideas inside a module — every module tutorial links back here with a small tag like origin-triple instead. Read all four now, once, and the modules will move fast because they don't have to stop and explain fundamentals every time one comes up.

Platform note Trusted Types (Track 2) is currently implemented only in Chromium-based browsers (Chrome, Edge, Opera, Brave). Every Track 2 module assumes you're running one of those. Track 1 (CSP) works in any modern browser.

The Four Primitives

  1. HTTP Headers & Origins
    What a response header actually is on the wire, and what "origin" means to a browser's trust model. Every CSP directive is enforced against an origin, not a URL — you need this distinction before Module 1.
  2. DOM Sinks
    The handful of DOM APIs that turn a string into live markup or running code (innerHTML, eval, document.write, script src). Both CSP and Trusted Types exist to control what reaches these APIs.
  3. CSP Vocabulary
    Policy, directive, source expression — the exact nouns every CSP module will use precisely and never redefine.
  4. The JS Prototype Chain
    How instanceof actually works under the hood. This is the one that pays off latest (Track 2, Phase 4) but is cheapest to learn now, before you have a Trusted Types mental model to unlearn.

How to use this layer

Don't try to memorize these pages. Skim them once so the vocabulary is familiar, then come back to a specific anchor whenever a module's tag-link sends you here. That's the intended workflow for the whole course.
