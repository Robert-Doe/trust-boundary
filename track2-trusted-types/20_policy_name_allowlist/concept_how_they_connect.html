Commonly Confused Pairs

Wrong statementThe correction
"`trusted-types` turns Trusted Types on." No — that's `require-trusted-types-for`. `trusted-types` alone, without the other directive, has no effect at all (nothing is enforced to check the allowlist against).
"`window.trustedTypes` IS a Trusted Types policy." No — it's the FACTORY that creates policy objects. `window.trustedTypes.createPolicy(...)` returns a policy; the global itself is not one.
"A `TrustedHTML` value and the `innerHTML` sink are the same concept." No — `TrustedHTML` is a value TYPE. `innerHTML` is a SINK (a property setter) that demands values of that type. One is data, one is a gate.
"If `require-trusted-types-for` is present, any policy name works." Only if `trusted-types` is absent. If it's present, ONLY the names it lists succeed — verified directly in Module 20's Proof B.

Scenario-Matching Quiz

1. A page has `require-trusted-types-for 'script'` but NO `trusted-types` directive at all. Can `trustedTypes.createPolicy('anything-i-want', {...})` succeed?
Reveal answerYes — with no `trusted-types` directive present, there's no name allowlist to fail against (Modules 16–19's exact setup, before Module 20 ever introduces the allowlist).
2. `policy.createHTML('<b>hi</b>')` returns a value. Which TWO of the four terms on this page are directly involved in producing it?
Reveal answer`window.trustedTypes` (the factory that made `policy` in the first place) and `TrustedHTML` (the type of the returned value). The two CSP directives aren't directly "involved" in this specific call — they already did their job earlier, by permitting `policy` to exist at all.
3. True or false: `trusted-types 'none'` and omitting `require-trusted-types-for` entirely have the same practical effect.
Reveal answerFalse, in one specific way — omitting `require-trusted-types-for` means sinks accept plain strings normally (Module 14's baseline). `trusted-types 'none'` alongside an ACTIVE `require-trusted-types-for` means sinks still demand TrustedHTML/TrustedScript, but NO policy can ever be created to supply one — every guarded sink becomes permanently unusable, closer to Module 15's zero-policy state than to no enforcement at all.
