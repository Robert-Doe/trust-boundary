Vocabulary Web · The Trusted Types Directive FamilyConcept: window.trustedTypes

This is the FACTORY COUNTER — the one JS global object every module since 16 has called .createPolicy() on. Unlike the two CSP directives, this is a real, live JS object, reachable and inspectable like any other global (typeof trustedTypes === 'object').

What it looks like

trustedTypes.createPolicy('name', { createHTML: (s) => s });
trustedTypes.isHTML(someValue);      // type-checking helper
trustedTypes.getPolicyNames();       // introspection (not used directly in this course)

Where you've seen it

  • Every module since 16 — trustedTypes.createPolicy(...) is the entry point for everything Track 2's Phase 3 modules test
  • Module 24 — DOMPurify.isSupported internally checks for this global's presence to decide whether to use Trusted Types at all

What it is NOT

It is not itself a policy, a directive, or a branded type. It's the FACTORY that produces Trusted Types policy objects (see that term) — and unlike those two CSP directives, it exists and is inspectable purely as ordinary JavaScript, with or without any CSP header present at all (though without require-trusted-types-for, nothing enforces that its output is actually required anywhere).

How this connects to the other terms window.trustedTypes is the JS-level entry point CSP's require-trusted-types-for/trusted-types directives govern access to. Calling trustedTypes.createPolicy() is what produces a Trusted Types policy object, whose create* methods produce TrustedHTML/TrustedScript/ TrustedScriptURL values.
